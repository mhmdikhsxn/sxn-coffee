## About The Project
**SXN Caffe** adalah proyek web *portfolio/concept store* yang dirancang dengan estetika minimalis modern, fokus pada interaksi UI yang mulus, *depth-based layering*, dan performa tinggi. Proyek ini dibuat untuk mengeksplorasi pengalaman pengguna (*user experience*) yang elegan dalam industri *food and beverage*.

## Tech Stack
* **Framework / Core:** React, TanStack
* **UI & Styling:** Tailwind CSS, shadcn/ui, Radix UI
* **Animation:** Framer Motion
* **Icons & Fonts:** Lucide, Google Font API
* **Deployment / PaaS:** Vercel
* **Maps & Extras:** Leaflet (v1.9.4), Open Graph

## Features
* **Elegant Product Grid:** Menampilkan katalog menu kopi dengan tata letak modern.
* **Smooth Micro-Interactions:** Animasi transisi halaman dan elemen interaktif yang responsif.
* **Responsive Design:** Dioptimalkan untuk berbagai ukuran layar (Mobile & Desktop).
